## Blocking (each with its failing input)

**B1. The scaled tolerance uses ONE global S, so an unrelated variable hides a non-stationary
one** (`SQP.cpp:1104-1115`).  `a A15`:
`f = 1e4 (x1 - x2^2)^2 + (x2 - 0.5)^2 + 1e5 x3`, box `[-2,2]x[-2,2]x[0,1]`, x0 = (-1, 1.5, 0).
x3 sits at its bound with gradient 1e5, so S = 1e5 and tolUsed = 1.0 for EVERY component.
Result: `CONVERGED, KKT conditions satisfied`, x = (0.2499774, 0.4999782, 0), stat 1.46e-2,
statBar 6.6e-8.  True optimum (0.25, 0.5, 0); true |grad L| over x1, x2 = 1.46e-2 = 1458 x
tolStat.  Controls (`b A15ctl`): slope of x3 = 0 or 1 -> certified at (0.25000000, 0.50000000),
true gradient 1.6e-7; slope 1e3 -> certified with true gradient 2.1e-3 (211 x); the same run
with `scaledStationarity = false` reaches (0.25000004, 0.50000004).  The driver scales x but
not f (optim05's S is 1.7e7, tolUsed 172), so this is reachable from an outerDict.
Fix: scale per component, `S_j = max(1, |df/dx_j|, sum_i |lambda_i dc_i/dx_j|, |lambda_b,j|)`,
which is what "the size of the terms whose cancellation grad L measures" means.

**B2. Step test against `||x||inf`, and QP step-bound rows counted as active bounds at x**
(`SQP.cpp:1081-1086, 1004, 1111-1113, 1129-1130`).  `a A3`:
`f = 10 (x1 - 0.6)^2 + 1e6 x2`, x1 in [0,1], x2 in [1e6, 2e6], x0 = (0.2, 1e6).
Iteration 0: `CONVERGED, KKT conditions satisfied`, x1 = 0.2 (optimum 0.6), true f'(x1) = -8,
stat 0.8, tolUsed 10, statBar 0.  Three defects compound: (a) `||d||inf <= 1e-4 max(1,||x||inf)`
lets x2 = 1e6 give x1 an allowance of 100; (b) the QP's step d1 = 0.8 reaches the row
`d1 <= hi - x1`, its multiplier 7.2 is added to grad L although x1 is 0.8 from that bound, and
no bound-row complementarity is checked; (c) that component is then dropped from the bar
("absorbed by the bound multiplier"), so statBar = 0.  Controls (`b A3ctl`): needs both the
large |x2| and the large slope; with x2 scaled to [0,1] the answer is right.  Through the
driver (x scaled to ~1) the allowance is 1e-4, so this exact form is a public-interface lie;
(b) and (c) remain in the driver.  Fix: `|d_j| <= 1e-4 max(1,|x_j|)` per component; a bound
row enters grad L, S and the bar exclusion only if the bound is active AT x (|x_j - bound|
within the feasibility tolerance); check complementarity of bound rows.

**B3. Curvature measured at the probe scale, gradient taken at a 10x smaller step**
(`SQP.cpp:386, 422-433` against `444-447`).  `a A5`: f = (x - 0.6)^2 + A sin(2 pi x / 5e-7),
x in [0,1], x0 = 0.1, a smooth (C-infinity) function whose wiggle period divides the noise
stencils (1e-3, 2.5e-4) and the first curvature probe (1e-6), so ECnoise reads the rounding
floor and L = 2.  A = 1e-10: `CONVERGED`, x = 0.6001168, statBar 5.0e-7, TRUE f' = -7.9e-4
(79 x tolStat; 1.2e-4 from the smooth minimum).  A = 1e-11: certified, true f' = -8.5e-5
(8.5 x).  Deterministic.  Contrived (aliasing), but it is the general hole: nothing at the
certificate checks the gradient at a step other than the one it was computed with.  Fix (cheap):
at a certificate, difference again with a second, non-commensurate step (e.g. 3.7 h, or central
if forward) and require agreement within the bar; or start the curvature probe at the FD step.
