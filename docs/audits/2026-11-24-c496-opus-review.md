## (6) Stopping
- **ff4fbdc8ca certifies a non-stationary point.** f = 1e8 max(0,.3-x)^2 + 10(x-.6)^2, relative noise 1e-9, x0=0, box [0,1]: "KKT conditions satisfied", stat 1.0e-8, x = 0.575. The true optimum is 0.6 and the true gradient there is -0.5. The step 0.05 and L=0.1 chosen at x=0 were never re-estimated; its own printed bound was 0.19, against tolStat 1e-5. Default gets x = 0.599998 and says unconverged.
- **"Never across a bound" is false**, for two reasons:
  - Steps and directions are reused at later iterates. min 2(x-1.5)^2 on [0,1] evaluates x = 1.0000002.
  - When no direction fits the box, the code goes forward anyway (359). **Shipped optim05 under auto:** T_feed h = 5.0e-02 scaled = 17.5 K, so 367.5 K is simulated. Declared max is 352.5 K, and the case warns of a cliff at ~353 K. The driver does NOT clip (evaluateAll, 1109-1121), so the Guide's "clipped by the caller" is also false for it.
- **79bf454c79, same family:** K=2e10, relative noise 1e-12, returns converged at x = 1, f = 1.6: "KKT satisfied within the gradient noise: ||grad L|| = 8.00, bar 5.05e+03". True optimum 0.6, f = 0. ff4fbdc8ca returns converged = 0 on the same input. Reasons:
  - The bar is stale: eL2 uses sigG from x=0, where f ~ 1e9.
  - A large B (from BFGS) makes d vanish, and d ~ 0 is read as "nothing to improve".
  - Bars have no upper limit relative to the objective, and grow with |lambda|.
  - The driver still prints CONVERGED, the KKT certificate and exit 0.
- **What 79bf tries to fix:** optim05 under auto exits 1 (stat 1.63e-5 vs 1e-5) where shipped and default SQP converge. My reading: that is an absolute tolStat on an objective of 6.6e8 (lambda 2.4e6), i.e. a relative residual near 1e-11. The remedy is a scaled stationarity test, not a noise excuse.
