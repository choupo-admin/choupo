# C184 slice 2: the thermodynamic starting profile as a recovery rung (2026-11-25)

Measured on branch `c184-slice2` (base `a8b15d762b`), native `-O2` build.  Written for DEV.md 4c
C184.  The architect's ruling for this slice: the default path stays byte-identical; the
thermodynamic profile is (a) the first rung of a retry when a simultaneous or full MESH returns NOT
converged from the default seed, and (b) opt-in by `seed thermodynamic;` in the column's
`operation`.  This file holds the evidence; the decision on the default is later and is not made here.

## 1. The witness: a wide-boiling column the default start cannot solve

`tutorials/steady/distillation/column22_wide_boiling_retry` (new): toluene / n-hexadecane, ideal
gamma-phi, 100 kmol/h 50/50, a 300 K liquid feed, 1 atm, 20 stages, feed on 10, R = 3, D = 50 kmol/h.

| run | result |
|---|---|
| default start (T_feed - 5 K .. T_feed + 15 K = 295 .. 315 K), no retry (sabotage: `retryWithThermoSeed = false`, engine rebuilt) | `Converged: NO`, 80 Newton iterations, |F| = 5.3e-02, exit 2, `unit 'column22' failed to converge` |
| default start, retry as shipped | `[solver] column 'column22' (simultaneous): the MESH from the default seed did NOT converge; it was re-solved from the thermodynamic profile (the same equations, never another model) -- CONVERGED in 8 Newton iterations (the default seed stopped at |F| = 0.053034)`; exit 0; the same line is an `info` advisory |
| `seed thermodynamic;` | `[seed] thermodynamic profile at P = 1.013e+05 Pa: feed bubble point 410 K, dew point 531 K; relative volatilities up to 273 ...; stage T 383.8 K (top) -> 559.7 K (bottom)`, converges in 8 iterations, no retry line |
| `model fullMESH;` (same column) | CMO phase NOT converged (80 iterations), the full MESH from it NOT converged (|F| = 0.15); retry from the profile with the CMO flows: `CONVERGED in 24 Newton iterations`; exit 0 |

The gate holds all four (`bin/curate/check_column_diagnosis.py` arm (f)); sabotaged and restored, both
outputs are in the report.  The profile is physical (384 K and 560 K are the normal boiling points
of the two products at 1 atm).

### How common is it?  A scan of 28 wide-boiling variants (scratch, not shipped)

Seven pairs (n-hexane/n-decane, n-heptane/n-dodecane, n-hexane/n-eicosane, benzene/n-eicosane,
n-pentane/n-dodecane, toluene/n-hexadecane, n-heptane/n-decane) at four specifications each
(R, N, feed T = 1.5/15/300 K, 3/20/300 K, 2/15/250 K, 5/25/300 K), 1 atm, 100 kmol/h 50/50, D = 50:

* the default start did NOT converge in **28 of 28**;
* the retry converged **15 of 28** (in 4 to 59 iterations) and failed on 13 (|F| from 5e-4 to 2e-2
  after 80 iterations: relative volatilities of 150 to 270 and product purities of 1e-8 and beyond
  leave the stage equations nearly flat, and the Newton, not the seed, is the limit there);
* where the retry fails, the `[diagnosis]` block says so ("a retry from the thermodynamic profile
  ... was tried: ... stopped at |F| = ...") and the first attempt's iterate is kept.

Other probes: benzene/toluene with the feed at 200 K converges from the default start only through
the retry (a case outside any property window, not shipped); at 10 and 20 bar the default start
converges in 8 and 9 iterations, `seed thermodynamic;` in 4; a 50-stage R = 60 benzene/toluene
column (the slice-1 hard column) fails both ways and its diagnosis now says a retry was tried.

Summary.

* **13 of 21** converge both ways, to the SAME answer: largest relative KPI difference 1.5e-09 (the
  solver tolerance).  Of these, 9 take fewer iterations from the thermodynamic profile, 3 the same, 1
  more (column03); median 9 default against 8; total over the 13: 263 against 158.
* **8 of 21 do NOT converge or do not run from the thermodynamic profile**, although the default
  converges on every one: acetone06/07 (the Newton stops at 80 iterations) and the acetone plant (its
  recovery search finds no distillate rate at which the column solves), crystalliser09, column21 (a designSpec loop that visits many
  columns), and the three aqueous-chemistry columns (column13, stripper01/02), where the profile's
  composition leaves a stage without an aqueous phase and the speciation refuses.
* So the thermodynamic profile is a better START on ideal-vapour hydrocarbon columns and a worse one on
  strongly non-ideal and electrolyte columns.  That is the measured reason it is a recovery rung and an
  opt-in, not the default; a later decision on the default would need the 8 to be understood first.
  (Speciation errors inside a retry are caught: the retry is announced as not possible and the first
  attempt's verdict stands; they cannot occur on a column that converges from the default start,
  because no retry is made then.)

## 3. What the profile is (Theory Guide `sec:column-thermo-seed`)

Feed bubble and dew points at P (`bubbleTWithItsVapour`, `DistillationColumn.cpp:559`, over
`bubbleT`, `src/thermo/SaturationCurves.H:95`; and `DewPoint::compute`,
`src/unitOperations/saturation/DewPoint.H:93`); alpha_i = K_i / K_ref at the
bubble point; d_i/b_i = c alpha_i^S with S = (N-1)/2 and sum d_i = D/(D+B) sum f_i by bisection on ln c;
x_ji proportional to b_i alpha_i^(S (N-1-j)/(N-1)); T_j the bubble point of x_j.  One pressure: the
simultaneous MESH has no pressure profile.  The factor 1/2 in S is a judgement (Gilliland's N_min ~ N/2),
not a published value.

## 4. Not done

* `WangHenke` (`DistillationColumn.cpp`, the bubble-point sweep) has no Newton and no retry; its seed is
  untouched.
* The retry is one rung: no continuation, no adaptive ladder (slice 3).
* The thermodynamic seed is not offered through `system/solverDict` (only `operation`), unlike
  `newton`/`lineSearch`.
* A reactive column's profile uses the same blended feed composition as its default seed; no reactive case
  needed the retry in the corpus, so the reactive retry path (phase 1 legacy, phase 2 continuation re-run) is
  not witnessed by a shipped case.
