# Pack: a tablet plant from a drug and a dose

budget: 2100 words (~3360 tokens)

Read this pack when the student wants a pharmaceutical solid-dose plant (tablets) for THEIR drug.
A recipe: take the scaffold this pack names, change the listed keys, run, read.
Grammar of the plan, machines, utilities and money is in the pack `batch-plant`; the building in `layout`.
Without a shell: hand the case over, say it was not run, and tell the student to use File > Complete 0/ and then Run, pasting back every FAILED, WARNING, ERROR or INCOMPLETE line.  With a shell and an engine, run it yourself and say so.

## 1. Ask the student first (nothing else is needed)

1. Drug name and molar mass (g/mol) of the form in the tablet (salt, if a salt).
2. Strength per tablet (mg), core mass (mg), coat percent.
3. Tablets a year, lot size (kg of final blend), route: wet granulation (the shipped case) or direct compression.
4. One or two strengths.
5. A new strength of a shipped product: the same blend at another weight (the 5 mg is the 10 mg tablet halved), or the same core with API replacing lactose?  If the student did not say, ask once.

Never invent a molar mass, a price or a rating: ask, or write the number as "ASSUMED" with a `source`.

## 4. The order of work

1. Copy, clean, rename (section 2).
2. New drug record; component name in `thermoPhysPropDict`; delete the old record.
3. Rewrite the feeds. Basis rate B tablets/h . For a SOLID feed: kmol/h = mg per tablet x 1e-6 x B / MW, written twice (overall and inside `phases { solid { componentMolarFlows ... } }`). A water feed: `componentMassFlows { water X kg/h; }` with `phase liquid;`. Binder water = binder kg/h x (1-w)/w. Air feeds: leave, check the dryers (section 6).
4. `postDict`: `perYear`, lot `mass`, then the machine ratings.
5. Prices: price per kg of `packagedTablets` = EUR per tablet x tablets per hour / kg per hour of `packagedTablets` (read kg/h in the first stream table, then redo).
6. Delete the estimate files and complete `0/`: `bin/choupo-init0 <case>`. Lint: `bin/choupo-lint <case>`.
7. Run: `runCase -f <case>`. Paste back every line containing FAILED, WARNING, ERROR or INCOMPLETE.
8. Fix what the refusals say (section 6), run again, until exit 0.
9. Read the deliverables (section 7); write `DESIGN.md` with every ASSUMED number and what the plant does not model (section 9).

## 5. One worked change (measured): metformin HCl 500 mg, 600 kg lots, 100 M tablets a year

Copy of `tutorials/batch/plant/donepezil01_tablets`; core 600 mg, packed tablet 0.618 g; MW of metformin hydrochloride C4H11N5.HCl = 165.62.

* API rate: 500 mg x 1e-6 x 666 667 tablets/h / 165.62 = 2.01264 kmol/h. `0/apiFeed` becomes:

```
componentMolarFlows { metforminHydrochloride 2.01264 kmol/h; }
T 298.15 K;  P 1.01325 bar;
phases { solid { componentMolarFlows { metforminHydrochloride 2.01264 kmol/h; } } }
```

* The other eleven feeds, same arithmetic from the formula (lactose 5, starch 10, cellulose 60, binder 20 mg and so on per tablet).
* `postDict`: `perYear 61800 kg;` (100e6 x 0.618 g), `lot { mass 600 kg; }`, `itemMass 0.6 g` (press) and `0.618 g` (packaging).
* Machines then refuse (utilisation 1.87): raise the ratings to granulator 2.5 m3, fluid bed 3.0 m3, blender 2.0 m3, pan 1.5 m3 (a vendor's data sheet in a real project; say ASSUMED).
* Dryers: scale `0/fbdAirIn` to 700 kmol/h and `0/coatingAirIn` to 500 kmol/h.
* Price: 0.03 EUR/tablet x 660 000 / 413.6 kg/h = 47.87 EUR/kg for `packagedTablets`.
* Result: lot 592 kg, 105 lots a year, limiting step the fluid bed (4.25 h) and the packaging line (11 h), FCI 24.1 M EUR, NPV about -80 M EUR: a dedicated GMP line does not pay on a 0.03 EUR generic. Say that in the report.
* Direct compression: delete `binderPrep`, `granulator`, `fbdAirHeater`, `fluidBedDryer`, `mill` from `system/flowsheetDict` and feed the powders to `finalBlender`; delete their `0/` files, their stages, cleaning, sizing and quote entries in `postDict`, their items and room `equipment` entries in `layoutDict`, their prices in `constant/economics`; then init0. It ran at the first attempt.

## 6. The refusals the student will meet

| What the engine prints | What it means and the remedy |
|---|---|
| `ThermoPackage: component 'X' not loaded` or `stream state '...': component 'X' is not in the package` | stale estimate files in `0/` still name the old drug: delete the files whose header says ESTIMATE, run `bin/choupo-init0 <case>` |
| `runCase: '...log.choupoSolve' exists; pass -f` (exit 1) | not a case failure: `runCase -f <case>` |
| `ratedMachine '<unit>': the machine does NOT fit the lot -- utilisation 1.87 ...` and the run stops (exit 2) | the lot is bigger than the rating: raise `nominalVolume`, or declare `installed { count 2; }`, or a longer stage. The message names the exact remedy |
| `[SolidDryer] WARNING ... [heat-bound]`, run still exits 0 | NOT refused: the air cannot dry the granules; scale `0/fbdAirIn` or `0/coatingAirIn` until `[isotherm-reached]` |
| a quote or price missing: refusal naming the item, or a price silently absent | price EVERY inlet (`price 0;` with a provenance for air); a quote needs `source` and `reason` |
| `hvacGrade` refusal | each grade needs a quote `hvacGrade <G>; valuePerSupplyAir <EUR per m3/h>;` (pack `batch-plant`, section 5) |
| layout refusal naming a unit | a deleted unit is still in a room's `equipment` or in `items ( ... )` of `system/layoutDict` |
| Exit 0 but NPV absurd | the price is per kg of the stream, not per tablet (step 5) |

Grep the log for `FAILED`, `INCOMPLETE`, `WARNING`, `ERROR` before quoting any number.

## 8. Two strengths on one line (multi-product), in ten lines

Copy `tutorials/batch/plant/donepezil02_two_strengths`; its `system/postDict` is the model. In `batchPlan` replace `production` by:

```
products ( { product strength10; perYear 26121 kg;  stages ( { stage coating; changeoverTo { strength5 12 h; } source "..."; reason "..."; } ); source "..."; reason "..."; }
           { product strength5;  perYear 8707 kg;   stages ( { stage compression; operatingTime 14 h; source "..."; reason "..."; } ); source "..."; reason "..."; } );
campaignOrder ( strength10 strength5 );
```

A product's `stages` entry overrides a stage's time for that product; `changeoverTo { <next> <hours> h; }` is the clean after it, which depends on the DIRECTION (yellow then white is longer). A lighter tablet needs `itemMassByProduct { strength5 0.14 g; }` inside the press and packaging `rating`. The plan reads ONE balance per kg of product, so both strengths must be the same blend at different weights. With two products the order of campaigns does not change the year; it matters from three.

## 9. Do it by hand, and say so in DESIGN.md

No model of granulation end point, blend or content uniformity, hardness, dissolution or coating. Machines are mass boxes checked for FIT only; the press is also checked for dwell time and compaction force when the case declares the data (section 10). No capsule filler, filling line, lyophiliser or sterilising filtration (declare `splitter` placeholders as `massRate` machines, quote them, say nothing is modelled). Crew is a table you declare. HVAC is sensible heat only. One price per product for the whole life. Every kept number from the base case is an ASSUMED placeholder: replace it with a cited figure or defend it.

## 10. The press: dwell time, effectiveness, compaction force (DEV.md 4c C270)

A catalogue speed is not a real speed.  The punch flat `L` stays under the roll for `t = L / (pi D n)` (pitch circle `D`, turret `n` rev/s); a formulation needing `t_min` caps the speed at `n_max = L / (pi D t_min)`.  Add to the press's `designRules`, beside `rating`, each block with `source`/`reason` (worked: `tutorials/batch/plant/tabletPress01_dwell_and_force`):

```
dwell { punchFlat 8 mm; pitchCircle 0.30 m; minimumDwellTime 10 ms; source "..."; reason "..."; }
effectiveness { availability 0.90; performance 0.95; quality 1.0; source "..."; reason "..."; }
compaction { material "..."; targetTensileStrength 2 MPa; punchTipArea 99.93 mm2; maxCompressionForce 80 kN;
             trueDensity 1.6374 g/cm3;   // optional: the tablet's thickness
             heckel { K 0.00906 1/MPa; A 0.6576; Pmin 30 MPa; Pmax 170 MPa; basis inDie; source "..."; reason "..."; }
             ryshkewitch { sigma0 34.17 MPa; kb 7.173; basis outOfDie; source "..."; reason "..."; }
             source "..."; reason "..."; }
```

* The four curve constants come from `op:compactionFit` on the student's own dataset (`tutorials/props/powder/compaction01_mcc`); ONE material, no mixture rule.  Never invent them; absent, the run says the press was NOT checked.
* `quality` below 1 while the flowsheet's splitter already rejects tablets: announced, the rejects counted twice.
* Refused: a target at or above `sigma0`; a solid fraction below the line's zero-pressure density.  Announced: a pressure outside `Pmin`-`Pmax`, `inDie` against `outOfDie`, a force above `announceAbove` of the maximum.
* Exercise, predict before you run (measured on the witness, utilisation 0.76): `minimumDwellTime 15 ms` refuses (1.14, two presses); OEE 0.55 refuses (1.18); demand +17 % leaves the press at 0.76 (the check is per lot) and raises the lots from 102 to 119.
* The minimum dwell is the formulation's, measured (a compaction simulator), not the press maker's: for pure MCC, Wuensch et al. 2020 (Pharmaceutics 12, 310) found the same tensile strength from 10 to 130 ms.
